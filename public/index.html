Как начать

  1. Скопируйте Base URL: https://zetaai-lcgb.onrender.com/v1
  2. Получите ключ zeta-sk-… выше
  3. Выберите модель из списка (поле id)
  4. Отправьте запрос как в OpenAI
curl https://zetaai-lcgb.onrender.com/v1/chat/completions \
  -H "Authorization: Bearer zeta-sk-XXXX" \
  -H "Content-Type: application/json" \
  -d '{"model":"MODEL_ID","messages":[{"role":"user","content":"Привет!"}]}'
from openai import OpenAI
client = OpenAI(
  base_url="https://zetaai-lcgb.onrender.com/v1",
  api_key="zeta-sk-XXXX",
)
r = client.chat.completions.create(
  model="MODEL_ID",
  messages=[{"role": "user", "content": "Привет!"}],
)
print(r.choices[0].message.content)
